## TCP/UCLA MRI data

### Usage:
1. Execute `./setup.sh` and activate the .venv
    - For nix users: run `nix-shell`
2. Provide the `csv_data` folder with data
3. Run `python main.py`

### Contents:
 - original_data - data provided by customer
 - csv_data - CSV files extracted from Excels and TSVs
 - data - fully processed data ready for study: JSON and flat NPZ with legend
 - scripts - scripts for working with data
 - charts - charts generated by visualization scripts
 - reports - reports generated by analysis scripts
 - instruction_gemini.pdf - challenge for students
